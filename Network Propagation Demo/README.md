# Network Propagation Demo

## Rationale for NeuroAI students

Propagation is a basic question in both brains and artificial networks: when activity appears in one part of a system, does it die out, spread, amplify, oscillate, or preserve useful structure? This explainer lets students compare how network topology and directionality shape the movement of activity through ring and feedforward architectures.

For NeuroAI, the relevance is that propagation links local update rules to global computation. It gives students an intuition for signal flow, recurrence, stability, and the difference between architectures that merely transmit activity and architectures that transform it in useful ways.
