Dynamical Systems · Delay-Differential Equations

Why Delay Kills Stability

A system that stabilises itself perfectly can still oscillate wildly — if it acts on information that is even slightly out of date. Here is the formal mechanism, built from first principles.

§1 — Start with something that always works

Consider the simplest negative-feedback system:

$\dot{x}(t) = -\alpha\, x(t), \quad \alpha > 0$

Whatever initial condition you give it, $x$ decays exponentially: $x(t) = x_0 e^{-\alpha t}$. The equilibrium at zero is globally stable. Try it below — vary $\alpha$ and watch.

The single eigenvalue is $s = -\alpha$, which sits firmly in the left half of the complex plane. Distance from the imaginary axis $= \alpha$. Larger $\alpha$, safer.

§2 — Now add a delay

Suppose the feedback mechanism can only act on $x$ as it was $\tau$ seconds ago. The equation becomes:

$\dot{x}(t) = -\alpha\, x(t - \tau)$

The structure looks identical. The same negative sign, the same gain $\alpha$. Yet something fundamentally different happens for large enough $\tau$.

Intuition check: if $x$ was positive a moment ago but has since swung negative, the delayed feedback still pushes it negative — in the wrong direction. A corrective force that arrives late can amplify rather than damp.

Drag the delay slider. Past a critical threshold the system starts to oscillate, then blow up.

§3 — Where the eigenvalues went

For the ODE $\dot{x} = -\alpha x$, we substituted $x = e^{st}$ and got one equation, one root: $s = -\alpha$.

Try the same ansatz for the delayed system. Substituting $x(t) = e^{st}$ gives:

$s\,e^{st} = -\alpha\,e^{s(t-\tau)} = -\alpha\,e^{st}e^{-s\tau}$

Cancel $e^{st}$ (never zero):

$$s + \alpha\, e^{-s\tau} = 0 \qquad \text{(characteristic equation)}$$

This is a transcendental equation in $s \in \mathbb{C}$. Unlike a polynomial, it has infinitely many roots. That is the key structural difference — the delay inflates the eigenvalue problem from finite to infinite dimension.

Why infinitely many? $e^{-s\tau}$ is an entire function with infinitely many zeros when composed with the left-hand side. Intuitively, a delay-differential equation carries memory of the whole past interval $[t-\tau, t]$ — that is an infinite-dimensional state space.

§4 — The crossing mechanism

Stability requires all roots to have $\text{Re}(s) < 0$. As $\tau$ grows, infinitely many roots shift. We ask: which root crosses first, and when?

Find the critical delay analytically

At the stability boundary, $\text{Re}(s) = 0$, so $s = i\omega$ for some real $\omega$. Substitute into the characteristic equation:

$i\omega + \alpha\,e^{-i\omega\tau} = 0$

Expand the exponential using Euler's formula:

$i\omega + \alpha(\cos\omega\tau - i\sin\omega\tau) = 0$

Separate real and imaginary parts:

$$\text{Re}: \quad \alpha\cos\omega\tau = 0$$ $$\text{Im}: \quad \omega - \alpha\sin\omega\tau = 0$$

From the real part: $\cos\omega\tau = 0 \Rightarrow \omega\tau = \pi/2 + k\pi$. The smallest positive solution is $\omega\tau = \pi/2$, giving $\omega = \alpha$ (check: $\alpha - \alpha\sin(\pi/2) = \alpha - \alpha = 0$ ✓).

$$\boxed{\tau_c = \frac{\pi}{2\alpha}}$$

Below $\tau_c$: all roots in the left half-plane — system stable. At $\tau_c$: a conjugate pair $s = \pm i\alpha$ hits the imaginary axis — Hopf bifurcation. Above $\tau_c$: that pair crosses into the right half-plane — oscillatory instability.

§8 — What you now know

The mechanism is fully explicit:

(1) Delay converts the finite-dimensional eigenvalue problem into an infinite-dimensional transcendental one — infinitely many characteristic roots.

(2) As $\tau$ increases, the leading root pair $s = \sigma \pm i\omega$ migrates rightward. The crossing speed $d\sigma/d\tau > 0$ at $\tau_c$ confirms this is a genuine destabilisation, not an artefact.

(3) The critical delay is $\tau_c = \pi/(2\alpha)$: stronger feedback is both stabilising (faster decay when acting) and fragile (smaller delay budget before instability). This is the essential tension in every feedback-with-delay system, from pupillary reflexes to internet congestion control.

The take-away: it is not that delayed feedback is bad — it can still stabilise when $\tau < \tau_c$. The danger is that the delay budget shrinks as $1/\alpha$. Faster, more aggressive feedback actually reduces the margin. Tuning for speed without accounting for latency is a recipe for oscillation.
