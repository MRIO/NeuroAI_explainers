Section I

The McCulloch–Pitts Neuron

In 1943, Warren McCulloch and Walter Pitts asked a radical question: what is the minimal mathematical object that can capture what a neuron does? Their answer stripped away everything — axon morphology, ion channels, neuromodulation — and kept only the essence: sum inputs, fire if the sum exceeds a threshold.

Before we see what this abstraction can do, let's examine honestly what it keeps and what it throws away.

Section II

Recognizing Patterns with Weights

A single MP neuron is a linear classifier. Its weights encode a template — a preferred pattern — and it fires when the input sufficiently resembles that template.

In vision, simple cells in V1 respond preferentially to oriented edges. This is not magic: it's a consequence of their receptive field weights. Below, you can sculpt a weight pattern on a 5×5 input grid and see whether the neuron responds.

Section III

The Limits of a Single Neuron —
and a Very Biological Question

Consider XOR: a circuit that outputs 1 when exactly one of two inputs is 1, and 0 otherwise. This is trivial in digital electronics. Yet a single MP neuron cannot compute it.

Before we prove this mathematically, think about it biologically. Here is the question for you:

Discussion question: Imagine a pyramidal cell receives input from two distinct dendrites — one from the left hemisphere, one from the right. Both synapses produce the same EPSP amplitude at the soma when activated alone. Can this neuron distinguish whether the input came from the left dendrite, the right dendrite, or both?

The answer is no — not at the level of the soma. The soma only sees voltage, not origin. Two identical EPSPs, regardless of where they were born, add to the same somatic depolarization. The soma is a linear summation device (to first approximation), and linear summation is precisely what makes XOR impossible.

📐 Why XOR is not linearly separable — try to draw a separating line
XOR has 4 points. Drag the line (blue dots) to try to separate ● from ○. It's impossible.

Formally: a single threshold unit can only implement linear decision boundaries — hyperplanes in input space. XOR is not linearly separable. No matter how you draw a single line through the 2D input space, you cannot put the (0,1) and (1,0) points on one side and the (0,0) and (1,1) points on the other.

But wait: real dendrites are not passive cables. Dendritic spikes, NMDA receptors, and compartmental nonlinearities mean that a real pyramidal cell can implement something akin to XOR — but through dendritic computation, not somatic summation alone. The MP neuron, by collapsing all inputs into a flat weighted sum, discards this spatial structure entirely.

The fix is not to make individual units smarter — it's to stack them.

Section IV

Adding Depth — Hidden Layers Solve XOR

Two neurons in a hidden layer can each draw a linear boundary. The output neuron then looks at which boundaries were crossed. Together they can represent XOR.

Layers and cortical hierarchy

This maps beautifully onto visual cortex: V1 neurons detect oriented edges (layer 1), V2/V4 neurons combine edges into curves and shapes (layer 2), IT neurons respond to complex objects (layer 3). Each layer extracts a more abstract, more useful representation.

Section V

Universal Function Approximation

The Universal Approximation Theorem (Cybenko 1989, Hornik 1991) is one of the most remarkable results in all of machine learning. It states:

A feedforward network with a single hidden layer of sufficient width, using a non-linear activation function (e.g. sigmoid, ReLU), can approximate any continuous function on a compact domain to arbitrary precision.

Let's build intuition for what this means.

Each hidden neuron contributes a "bump" or "sigmoid ramp." The output layer learns to add and subtract these bumps to reconstruct the target function. With enough neurons, any continuous function yields to this construction.

Can a feedforward network approximate recursive functions?

No. This is a fundamental architectural limitation, not just a practical one. Consider the Fibonacci sequence: f(n) = f(n-1) + f(n-2). Each output depends on previous outputs. A feedforward network is acyclic — information flows only forward, one pass, no memory of past activations.

FFNs cannot represent: recursive functions, programs with loops, algorithms where the number of steps depends on the input (like Quicksort or GCD). For those, you need recurrence — either RNNs, LSTMs, or Transformers with explicit positional memory. Turing-complete computation requires cycles.

This maps back to neuroscience: the feedforward sweep through cortex computes a rapid but fixed-depth transformation. It's recurrent cortical loops that allow for iterative refinement, working memory, and context-dependent processing.

The key insight: depth is exponentially more efficient than width for representing compositional functions. A deep narrow network can represent functions that would require an exponentially wide shallow network. This is why deep learning works — and why the brain uses cortical hierarchy rather than one enormous layer.

Why non-linearity is not optional

Depth alone is not enough. Without a non-linear activation function between layers, any stack of matrix multiplications collapses into a single matrix — algebraically identical to a one-layer network. The non-linearity is what makes each layer genuinely add new representational power.

True universal approximation requires: (1) at least one hidden layer, (2) a non-linear activation function — linear nets collapse to a single affine map regardless of depth, (3) sufficient width — in theory unbounded; in practice width scales with the complexity of the target function. For approximation error ε on a d-dimensional input, required width can grow exponentially in d — the "curse of dimensionality."
