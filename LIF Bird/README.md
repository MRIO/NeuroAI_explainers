# LIF Bird Shishi-Odoshi Neuron

## Rationale for NeuroAI students

This standalone shishi-odoshi neuron uses a physical analogy to make leaky integrate-and-fire dynamics visible. Input fills the system, leak drains it, threshold triggers a reset, and refractoriness shapes the timing of repeated events, turning an abstract differential-equation model into an embodied mechanism.

For NeuroAI students, the value is that it makes spike timing feel causal rather than symbolic. Once the analogy is clear, concepts like rheobase, threshold crossing, reset, and firing frequency become easier to connect to both biological spiking neurons and event-based computational models.
