# Two Neuron Recurrent Dynamics

## Rationale for NeuroAI students

Two-neuron recurrent networks are small enough to analyze completely, but rich enough to show the core behaviors that make recurrent systems interesting: fixed points, oscillations, multistability, attractor basins, and sensitivity to connection weights. This explainer makes those behaviors visible by linking the network diagram, time traces, phase portrait, nullclines, fixed points, and local eigenvalues.

For NeuroAI students, the demo is useful because it treats a neural circuit as both a computational module and a dynamical system. The same kinds of two-unit interactions are the local building blocks underneath larger recurrent and multilayer demos: by studying the small module first, students can understand what mutual excitation, inhibition, self-coupling, bias inputs, memory, switching, winner-take-all behavior, and stability transitions mean before asking how those dynamics scale across many neurons and layers.
