# Adaptive Exponential Spiking Neuron Phase Space

## Rationale for NeuroAI students

The adaptive exponential model adds important biological structure to the simpler integrate-and-fire picture: spike initiation, adaptation, reset, and changing excitability. This explainer uses phase space to show how voltage and adaptation interact to produce firing patterns rather than presenting spikes as isolated threshold events.

For NeuroAI students, the relevance is that phase-space thinking scales beyond this one model. It helps students analyze stability, nullclines, attractors, excitability, and transitions between regimes, which are recurring ideas in neural dynamics, recurrent networks, and biologically grounded AI models.
