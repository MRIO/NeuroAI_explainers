# RNN Eigenspace Explorer

## Rationale for NeuroAI students

Eigenvalues and eigenvectors are often introduced abstractly, but in recurrent neural networks they directly shape trajectories, stability, oscillations, and memory. This explainer makes eigenspaces visible by linking the recurrent weight matrix to the paths taken by network states over time.

For NeuroAI students, the demo is relevant because linearized dynamics are a common language across neuroscience and machine learning. The same ideas help explain fixed points in neural population activity, modes in trained RNNs, low-dimensional dynamics, and why small changes in recurrent weights can qualitatively change behavior.
