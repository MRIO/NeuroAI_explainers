# DIY Receptive Field

## Rationale for NeuroAI students

Receptive fields are one of the most important bridges between stimulus space and neural representation. This explainer lets students build and probe a simple receptive field, making it clear how a neuron's selectivity can be described by the pattern of inputs that drive it.

For NeuroAI, the demo is useful because it connects classical sensory neuroscience to feature detectors in artificial networks. Students can use it to reason about weights as filters, pattern recognition as geometry, and the limits of single-unit explanations when moving toward deeper or recurrent systems.
