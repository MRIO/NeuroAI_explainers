Vector Field Studio

A self-contained HTML and JavaScript port of the classic 2-D vector-field applet. It keeps the preset catalogue, draggable view controls, particle and vector displays, field-line overlays, and rectangle-based circulation or flux measurements in one file.

What To Try
  • Switch between gradient fields and rotational fields to see when the surface view matters.
  • Use measure mode to compare circulation in rotational flows against flux in radial flows.
  • Write your own potential or vector field at the bottom of the control panel.
How To Drive It
  • Drag the canvas to rotate or zoom, depending on the selected mouse mode.
  • When measure mode is active, drag a rectangle to compute circulation or flux.
  • Force mode adds inertia, so use Kick to inject velocity.
