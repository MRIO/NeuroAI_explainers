# Vector Field Studio

## Rationale for NeuroAI students

Vector fields provide a visual language for dynamical systems: each point in state space says where the system will move next. This studio lets students create and inspect two-dimensional systems, making concepts like fixed points, flows, attractors, and separatrices concrete.

For NeuroAI, the relevance is broad. Neural population activity, recurrent network states, motor control, and learning dynamics can all be studied as trajectories in state space. Building intuition with simple vector fields prepares students to understand richer neural dynamics without treating them as black boxes.
