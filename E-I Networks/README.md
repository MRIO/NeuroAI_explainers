# E-I Balanced LIF Network

## Rationale for NeuroAI students

Excitation-inhibition balance is one of the central organizing ideas connecting cortical physiology, dynamical systems, and artificial recurrent computation. This explainer lets students see how sparse spiking networks can stay active without saturating, and how changes in drive, inhibition, and connectivity move the system between silence, irregular activity, and runaway firing.

For NeuroAI, the demo is useful because it ties a biophysical neuron model to population-level computation. Students can use it to reason about stability, phase transitions, neurodynamics, variability, coding in recurrent circuits, and why balanced dynamics are often invoked when comparing biological neural networks with machine-learning models.
