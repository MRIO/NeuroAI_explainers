# Multi Layer Meanfield Network Experiments

## Rationale for NeuroAI students

These demos explore how simple nonlinear neural fields behave when arranged into layers with local, random, feedforward, and feedback connectivity. They are relevant because many NeuroAI questions live at this middle scale: not a single neuron, not a full trained model, but interacting populations whose dynamics create structured activity.

For students, the mean-field and grid variants provide a way to inspect how architecture shapes computation before training enters the picture. Changing leak, coupling, recurrence, and nonlinearities makes it easier to understand propagation, amplification, stability, attractor-like behavior, and how layered systems can transform spatial patterns.
