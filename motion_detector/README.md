# Reichardt-Hassenstein Motion Detector

## Rationale for NeuroAI students

The Reichardt-Hassenstein detector is a classic example of computation emerging from a small circuit motif. By combining delay and correlation across neighboring visual inputs, the circuit becomes direction selective without needing a high-level representation of objects or motion.

For NeuroAI students, the demo is relevant because it shows how algorithmic ideas can be implemented in neural hardware. It also provides a useful comparison point for convolution, temporal filtering, and learned motion features in artificial vision systems.
