# Small RNN Eigenspace Explorer

## Rationale for NeuroAI students

This compact RNN eigenspace explainer focuses on the same core idea as the larger version: recurrent weights define directions in state space that expand, contract, rotate, or preserve activity. The smaller interface is useful when students need the essential relationship between matrices and trajectories without extra visual complexity.

For NeuroAI, the relevance is that many biological and artificial recurrent systems can be interpreted through low-dimensional modes. This demo gives students a quick way to connect eigenstructure to memory, instability, oscillation, and controlled dynamics.
