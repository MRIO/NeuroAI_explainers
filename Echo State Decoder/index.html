Echo state decoder

Can a fixed random reservoir learn a figure eight?

The interesting trick is that the recurrent network is random and stays random. Its intrinsic dynamics expand a simple time signal into a high-dimensional neural state; learning is the low-dimensional readout back down to two arm angles.

Random recurrence A fixed recurrent network creates a rich temporal basis.
Transfer function Each unit passes input through tanh, adding nonlinear mixing.
Linear readout Only Wout is learned, by ridge regression onto q1 and q2.

At 0 the readout returns the rest pose. At 1 the trained decoder drives the full path.

1. Make the reservoir

Start with a random dynamical system.

The reservoir is a sparse recurrent network. Its weights are scaled below runaway instability, so recent input leaves a fading but useful trace across many neurons.

Why this is useful

The reservoir turns a low-dimensional drive into many nonlinear traces of recent history. The decoder then reduces that state back to the two numbers the arm needs.

x[t+1] = (1 - leak) x[t] + leak tanh(W x[t] + W_in u[t])
2. Train the decoder

The target path becomes target angles.

A figure-eight hand path is converted into shoulder and elbow angles with inverse kinematics. Ridge regression then fits a linear readout from the reservoir state to those target angles.

Two-link inverse kinematics

The path is deliberately reachable. Inverse kinematics gives the training targets, then linear regression finds the output weights from reservoir state to shoulder and elbow.

3. Run the arm

The slider gates the learned motion.

The trained decoder knows the full pattern. The slider blends decoded motion around the rest pose, so you can watch the same reservoir state contract toward stillness or expand into the figure eight.

The useful surprise

The internal network did not learn the arm. It only created a rich, time-varying basis through recurrence and transfer functions. A small trained readout is enough to turn that basis into joint angles.

Try pausing, lowering the drive, then raising it again. The decoded traces and arm path shrink and recover together.
